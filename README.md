# Garry's Mod Immersive Loading Screen

An FBI-themed, dynamic loading screen for Garry's Mod servers that fetches and displays real-time data about connecting players.

[**Live Demo / Preview**](https://guntersuperpenguin.github.io/loading-logo/)

## 🚀 Features

* **IP Geolocation:** Displays the approximate geographic location of the connecting player based on their public IP address.
* **Steam Profile Integration:** Fetches and displays public Steam profile data, including avatar, real name, account creation date, and total Garry's Mod playtime (more details are shown if the user's profile is set to public).
* **Immersive UI:** Styled as an encrypted FBI Secure Access Terminal with terminal-like network logs and loading progress.

## 🛠️ Installation & Setup

To use this loading screen on your Garry's Mod server, add the following command to your server console or `server.cfg` file:

```gmod
sv_loadingurl "https://guntersuperpenguin.github.io/loading-logo/"
```
